1️⃣  VALIDAR CONFIGURAÇÃO
    Windows:   .\validate-pwa-config.bat
    Linux/Mac: bash validate-pwa-config.sh
    Tempo: ~1 minuto
    
2️⃣  FAZER BUILD
    npm run build
    Tempo: ~2 minutos
    
3️⃣  DEPLOY EM HTTPS
    ⚠️  PWA requer HTTPS (obrigatório)
    ℹ️  Localhost OK para desenvolvimento
    
4️⃣  TESTAR NO MICROSOFT EDGE
    • Abrir URL
    • Clique ícone instalação (canto superior)
    • Confirme
    • App abre sem barra de navegador ✨
    Tempo: ~5 minutos
    
5️⃣  VALIDAR VIA DEVTOOLS (opcional)
    • F12 → Console
    • Cole: docs/pwa-validation-script.js
    • Veja relatório detalhado
    Tempo: ~2 minutos
